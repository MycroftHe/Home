# Event Commentary Standard

## Structure

Use this section order:

1. `一、事件概要`
2. `二、市场反馈`
3. `三、潜在后果`
4. `四、投资者反映与具体股票可能表现`
5. `五、结论`
6. `主要资料来源`

## Writing Standard

Each paragraph starts with a bold judgment sentence, followed by concise support:

```markdown
**A股反馈整体偏正面。** 后续句子提供事实、机制和影响，不重复上一节内容。
```

The prose should be direct, institutional, and useful for investors. Avoid inflated phrasing and broad claims that are not tied to evidence.

## Section Guidance

### 一、事件概要

State what happened, when it happened, and the verified status. If the event is partly unconfirmed, say so clearly in natural Chinese. Explain why the event matters in one or two paragraphs.

### 二、市场反馈

Add incremental information, not a second summary of the event.

Cover:

- Official/company/media reaction.
- Market price reaction, if available.
- Investor debate and sentiment.
- Domestic market interpretation, especially A股 mapping.
- Social/社区观点 only as sentiment, not hard fact.

Do not repeat basic facts already covered in `事件概要`.

### 三、潜在后果

Discuss impact on:

- Equity sectors and style.
- Large asset classes where relevant.
- Industry chain structure.
- Difference from prior market expectations.

### 四、投资者反映与具体股票可能表现

Map the event to investable directions:

- Direct subject company.
- Upstream/downstream supply chain.
- Competing companies.
- A股/H股/美股 mapping.
- Positive and negative candidates.

Use stock examples as “可能受关注/可能承压”, not deterministic recommendations.

### 五、结论

Summarize the trade and fundamental meaning. Include a clear risk reminder and the most important follow-up variables.

## Source Policy

Prefer:

- Exchange/regulator/company disclosure.
- 财联社、证券时报、财新、上证报、中证报、第一财经、21财经、华尔街见闻.
- Bloomberg, Reuters, MarketWatch, Barron's, CNBC, WSJ when relevant.
- 雪球 only for investor sentiment, and describe it as discussion/sentiment.

If no stable Chinese source is available, say that public searchable Chinese sources are limited instead of inventing citations.

## Delivery Standard

Markdown:

- Use normal Markdown headings.
- Use bold paragraph-opening judgment sentences.
- Include sources at the end.

Word:

- Use a business brief style.
- Preserve bold paragraph openings.
- Include an opening summary table with three cells: 核心判断、市场方向、投资含义.

Email:

- Send full commentary as HTML body.
- Preserve bold paragraph openings in HTML.
- Attach Word file.
- Use the existing digest SMTP configuration unless told otherwise.
